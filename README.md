# RT950 Custom UI

Альтернативная прошивка для портативной радиостанции **Radtel RT-950 Pro**. Интерфейс доступен на русском и английском языках. Прошивка использует штатный загрузчик и заводские калибровки радиостанции.

- Три рабочих слота A/B/C, режимы VFO и памяти, зоны каналов и сканирование.
- Голосовая связь, настройки CTCSS/DCS и мониторинг приёма.
- Вещательное FM-радио, GPS и функции APRS.
- Настраиваемые боковые клавиши, яркость и тайм-аут подсветки.
- Автосохранение настроек и экспорт и импорт резервных копий по кабелю.

Проект в разработке. Поддержка функций зависит от версии сборки. Проверка в ARM-модели дополняет испытания на радиостанции.

## Сборка

Версии имеют вид `MAJOR.MINOR.PATCH`. Для нового набора функций увеличиваем MINOR и начинаем PATCH с нуля. Для небольших исправлений и отдельных сборок в той же ветке увеличиваем PATCH. Например, после `0.68.1` небольшой выпуск получит `0.68.2`, а следующий функциональный выпуск — `0.69.0`. Тот же номер используется в имени BTF и на экране рации.

Для сборки в Windows нужны Python 3 и ARM GNU Toolchain 13.2.Rel1. Из корня проекта выполните команду, указав путь к каталогу `bin` инструментов.

```powershell
python source/custom/package_firmware.py --toolchain 'C:\arm-gnu\bin' --output firmware --image-only
```

Образ `.BTF` и его контрольная сумма появятся в `firmware/`. Образ можно установить вручную штатным обновлятором для RT-950 Pro.

## Экспорт штатных каналов

Утилита читает локальный дамп внешней памяти RT-950 Pro с разметкой 0.29 или его канальную область размером 31 680 байт. Она создаёт CSV с номерами каналов, зонами и частотами в герцах. Поля тонов, флагов и имени экспортируются в виде исходных шестнадцатеричных байтов. `stored_tx_hz` — частота, записанная в канале. Разрешение передачи определяется отдельно по настройкам штатной прошивки.

```powershell
python source/custom/oem_channels.py dump.bin channels.csv
```

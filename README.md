# Radtel RT-950 Pro Custom UI

Custom UI - альтернативная прошивка для **Radtel RT-950 Pro**, созданная для радиолюбителей. Идея проекта - сделать рацию удобнее в повседневной работе, чтобы в эфире реже отвлекаться на меню.

Готовые образы для установки штатным прошивальщиком доступны в разделе [Releases](https://github.com/wizado7/Radtel950/releases).

# Сборка и перенос каналов

## Сборка

Версии имеют вид `MAJOR.MINOR.PATCH`. Тот же номер используется в имени BTF, в комплекте сборки и на экране рации.

- **PATCH** увеличивается на один для каждой новой сборки с изменениями в прошивке. Сюда входят исправления, новые функции и проходы с несколькими этапами P. Повторная сборка того же кода сохраняет номер. После `0.76.9` допустима `0.76.10`.
- **MINOR** увеличивается на согласованном крупном рубеже проекта, например при завершении целой подсистемы. PATCH при этом сбрасывается в ноль. Количество закрытых за проход этапов само по себе не определяет повышение MINOR.
- **MAJOR** меняется при переходе к новому поколению прошивки. При повышении MAJOR сбрасываются MINOR и PATCH.

После `0.76.0` обычные сборки идут как `0.76.1`, `0.76.2` и далее. `0.77.0` начинается на следующем крупном рубеже.

Для сборки в Windows нужны Python 3 и ARM GNU Toolchain 13.2.Rel1. Из корня проекта выполните команду, указав путь к каталогу `bin` инструментов.

```powershell
python source/custom/package_firmware.py --toolchain 'C:\arm-gnu\bin' --output firmware --image-only
```

Образ `.BTF` и его контрольная сумма появятся в `firmware/`. Образ можно установить вручную штатным обновлятором для RT-950 Pro.

Фиксированная высота маяка входит в резервную копию schema 4 размером 8144 байта. Утилита и прошивка читают также schema 1–3 размером 8040, 8056 и 8140 байт. Для отката сохраните копию, созданную на предыдущей прошивке.

## Экспорт штатных каналов

Утилита читает локальный дамп внешней памяти RT-950 Pro с разметкой 0.29 или его канальную область размером 31 680 байт. Она создаёт CSV с номерами каналов, зонами и частотами в герцах. Поля тонов, флагов и имени экспортируются в виде исходных шестнадцатеричных байтов. `stored_tx_hz` — частота, записанная в канале. Разрешение передачи определяется отдельно по настройкам штатной прошивки.

```powershell
python source/custom/oem_channels.py dump.bin channels.csv
```

На станции со штатной 0.29 канальную область можно получить через кабель. Сначала определите актуальный COM через `settings_backup.py --list-ports`. Для чтения нужен Python с pyserial. Результат подходит обеим утилитам переноса каналов.

```powershell
python source/custom/read_oem_channels.py --port COMx oem-channels.bin
python source/custom/oem_channels.py oem-channels.bin channels.csv
```

Чтобы перенести выбранные FM-каналы, сначала выгрузите резервный файл со своей Custom UI. Затем укажите соответствия `OEM:CH` и создайте новый файл. В примере OEM-каналы 1 и 64 заменяют ячейки 10 и 11. Импортированные каналы получают запрет TX, а ранее выбранные слоты, ссылающиеся на эти ячейки, возвращаются в VFO. Имена приводятся к алфавиту рации и сокращаются до восьми знаков.

```powershell
python source/custom/import_oem_channels.py dump.bin current.rtcfg imported.rtcfg --map 1:10 --map 64:11
python source/custom/settings_backup.py --inspect imported.rtcfg
```

Загрузите файл через **Система → Импорт настроек**, утилиту `settings_backup.py --upload imported.rtcfg --port COMx` и подтвердите на рации. Проверьте список после автосохранения и перезапуска.
